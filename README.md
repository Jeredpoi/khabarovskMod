# khabarovskMod - BetterDiscord Plugin:

Плагин модерации для Discord сервера Хабаровск через контекстное меню пользователя в BetterDiscord.

## Описание

Плагин добавляет удобное меню модерации в контекстное меню пользователя (ПКМ по аватару). 
Основная идея — быстро выбрать пункт правил и сразу применить наказание или подготовить команду.
Плагин разработан для сервера **Хабаровск** и поддерживает правила проекта BlackRussia
(кроме пунктов 5.1, 5.2, 5.3):

- **Общие правила** (пункты 2.1 - 2.21)
- **Правила текстовых каналов** (пункты 3.1 - 3.5)
- **Правила голосовых каналов** (пункты 4.1 - 4.4)

## Установка

1. Убедитесь, что у вас установлен [BetterDiscord](https://betterdiscord.app/) версии **1.14.0 или новее**
2. Скопируйте файл `khabarovskMod.plugin.js` в папку `%AppData%\BetterDiscord\plugins\`
3. Перезапустите Discord
4. Активируйте плагин в настройках BetterDiscord

Начиная с версии 1.6.0 плагин работает на нативном BdApi — устанавливать
ZeresPluginLibrary больше не нужно.

## Использование

1. Откройте любой текстовый канал на сервере
2. Нажмите ПКМ по аватару пользователя
3. Выберите **Модерация** → Категория → Пункт правила → Наказание
4. Для форм наказаний используйте меню **📝 Формы наказаний** (устное/предупреждение/мут/бан)
5. Дополнительные инструменты доступны в **🔧 Инструменты модерации** (/user, /punish, очистка, история)

## Настройки

Плагин автоматически создает файл конфигурации `khabarovskMod.config.json` в папке плагинов.
Основные секции:

- **Форматы сообщений и команд** (messageFormats)
- **Категории наказаний** (punishmentsWithText / punishmentsWithTextAndCopy / punishmentsWithCopy)
- **Настройки команд** (defaultMuteTime / defaultBanTime)
- **Уведомления и логирование**
- **Настройки интерфейса** (цвета, размеры, отступы, иконки)

### Доступные переменные в формате сообщения:

- `{userId}` — ID пользователя
- `{punishment}` — название наказания
- `{ruleId}` — ID пункта правила (например, "2.15")
- `{rulesChannel}` — ссылка на канал с правилами

### Тексты наказаний

Устное предупреждение и предупреждение имеют отдельные формулировки,
остальные наказания используют общий формат `withText`:

- **Устное предупреждение** (`oralWarning`) — просьба не нарушать правила
- **Предупреждение** (`warning`) — обращение с указанием нарушенного пункта
- **Остальные** (`withText`) — упоминание, наказание и пункт правил

### Ссылка на канал правил

Чтобы в конце сообщения появлялась кликабельная ссылка на канал с правилами:

1. Включите режим разработчика в Discord (Настройки → Расширенные)
2. ПКМ по каналу правил → **Копировать ID канала**
3. Вставьте ID в поле **ID канала с правилами** в настройках плагина

Если поле оставить пустым, `{rulesChannel}` подставится пустотой и лишние
пробелы будут убраны автоматически.

### Пример конфигурации:

```json
{
  "settings": {
    "messageFormats": {
      "withText": "<@{userId}> +{punishment} по пункту {ruleId} правил",
      "onlyMention": "<@{userId}>",
      "commands": {
        "warn": "/warn user:<@{userId}> reason:{ruleId}",
        "mute": "/mute user:<@{userId}> time:90 reason:{ruleId}",
        "ban": "/ban user:<@{userId}> time: reason:{ruleId}",
        "permban": "/ban user:<@{userId}> time:365 reason:{ruleId}"
      }
    },
    "punishmentsWithText": ["Устное предупреждение"],
    "punishmentsWithTextAndCopy": ["Предупреждение"],
    "punishmentsWithCopy": ["Мут 90 минут", "Бан 7-15 дней", "Перманентная блокировка"],
    "commandSettings": {
      "defaultMuteTime": 90,
      "defaultBanTime": 7
    },
    "ui": {
      "compactMode": false,
      "showIcons": true,
      "accentColor": "#5865F2"
    }
  }
}
```

## Типы наказаний

### Устное предупреждение

Автоматически отправляет сообщение в текущий канал.

### Предупреждение

Автоматически отправляет сообщение и копирует команду `/warn` в буфер обмена.

### Мут 90 минут

Копирует команду `/mute` в буфер обмена.

### Бан 7-15 дней

Копирует команду `/ban` в буфер обмена.

### Перманентная блокировка

Копирует команду `/ban` с временем 365 дней в буфер обмена.

### Другие наказания

Копируют сообщение с упоминанием пользователя и информацией о нарушении в буфер обмена.
